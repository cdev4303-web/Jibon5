# বাংলা ক্যালেন্ডার ও বৈদিক পঞ্জিকা (Bangla Calendar & Vedic Panjika)

বাংলাদেশ ও পশ্চিমবঙ্গের নির্ভরযোগ্য আধুনিক বাংলা ক্যালেন্ডার, তারিখ রূপান্তরকারী, সরকারি ছুটির তালিকা, সনাতন বৈদিক পঞ্জিকা এবং জ্যোতিষ শাস্ত্রীয় শুভ বিবাহ লগ্ন ও মুহূর্ত সমন্বিত পূর্ণাঙ্গ ওয়েব ও অ্যান্ড্রয়েড অ্যাপ্লিকেশন।

---

## ✨ অ্যাপ্লিকেশনের প্রধান সুবিধাসমূহ

- **দ্বৈত আঞ্চলিক সংস্করণ:** বাংলাদেশ (বাংলা একাডেমি সংশোধিত পঞ্জিকা) ও পশ্চিমবঙ্গ (বিশুদ্ধ সিদ্ধান্ত ও সূর্যসিদ্ধান্ত ঐতিহ্যগত পঞ্জিকা)।
- **সনাতন জ্যোতিষ শাস্ত্রীয় বিবাহ লগ্ন:** বৃহৎ পরাশর হোরাশাস্ত্ৰ ও পঞ্জিকানুসারে গোধূলি লগ্ন, দিবা-রাত্রির রাশি লগ্ন, প্রশস্ত তিথি-নক্ষত্র ও শুভ মুহূর্ত বিচার।
- **সরকারি ছুটি ও তিথি উৎসব:** বাংলাদেশ ও পশ্চিমবঙ্গ সরকারের অনুমোদিত ছুটির তালিকা এবং সনাতন ও সর্বধর্মীয় উৎসবের পূর্ণ বিবরণ।
- **দৈনিক জ্যোতিষীয় পঞ্জিকা:** সূর্যোদয়, সূর্যাস্ত, তিথি, নক্ষত্র, যোগ, করণ, অমৃতযোগ, মাহেন্দ্রযোগ এবং রাহুকাল গণনা।
- **অফলাইন সাপোর্ট ও মোবাইল রেসপনসিভ:** সম্পূর্ণ অফলাইনে কার্যক্ষম, PWA সাপোর্ট এবং মোবাইল ফ্রেন্ডলি ইন্টারফেস।

## 📱 GitHub Actions দিয়ে সরাসরি APK তৈরির নিয়মাবলী (স্বয়ংক্রিয়)

এই রিপোজিটরিতে **GitHub Actions Workflow** আগে থেকেই সাজানো আছে। আপনার কম্পিউটারে Android Studio না থাকলেও GitHub নিজেই বিনামূল্যে আপনার জন্য APK তৈরি করে দেবে।

### ১. রিপোজিটরি GitHub-এ আপলোড করুন
```bash
git init
git add .
git commit -m "Initial commit for Bangla Calendar"
git branch -M main
git remote add origin https://github.com/<আপনার-ইউজারনেম>/<রিপোজিটরির-নাম>.git
git push -u origin main
```

### ২. স্বয়ংক্রিয়ভাবে APK তৈরি ও ডাউনলোড
1. আপনার GitHub রিপোজিটরির **"Actions"** ট্যাবে ক্লিক করুন।
2. বামদিকের মেনু থেকে **"Build Android APK"** দেখতে পাবেন।
3. `main` ব্রাঞ্চে পুশ করার সাথে সাথে এটি নিজে নিজেই বিল্ড শুরু করবে।
   - চাইলে আপনি নিজেও **"Run workflow"** বোতামে ক্লিক করে যেকোনো সময় ম্যানুয়ালি বিল্ড চালু করতে পারবেন।
4. বিল্ড সম্পন্ন হলে (সবুজ টিক চিহ্ন আসার পর), ঐ বিল্ড রানটির উপর ক্লিক করুন।
5. নিচের **"Artifacts"** সেকশনে **`Bangla-Calendar-Android-APK`** জিপ ফাইলটি পাবেন।
6. জিপটি ডাউনলোড করে আনজিপ করলেই পাবেন সরাসরি ইনস্টলযোগ্য **`Bangla-Calendar-v1.0-debug.apk`**!

## 💻 লোকাল কম্পিউটারে রান বা Android Studio দিয়ে বিল্ড করার নিয়ম

### ওয়েব অ্যাপ ডেভেলপমেন্ট মোডে চালানো:
```bash
# ডিপেন্ডেন্সি ইনস্টল
npm install

# লোকাল সার্ভার চালু (Port 3000)
npm run dev

# প্রোডাকশন বিল্ড যাচাই
npm run build
```

### Android Studio দিয়ে APK বিল্ড করা:
```bash
# ১. ওয়েব বিল্ড ও অ্যান্ড্রয়েড প্রজেক্ট সিঙ্ক করুন
npm run build:android

# ২. Android Studio-তে সরাসরি ওপেন করুন
npm run cap:open
```
Android Studio ওপেন হলে মেনু থেকে **Build > Build Bundle(s) / APK(s) > Build APK(s)** চাপলেই APK তৈরি হয়ে যাবে।

## 📂 প্রোজেক্টের গঠন (Project Structure)
- `src/` — সমস্ত React কম্পোনেন্ট, ক্যালেন্ডার ইঞ্জিন, জ্যোতিষীয় অ্যালগরিদম ও পঞ্জিকার ডাটা।
- `public/` — আইকন, ম্যানিফেস্ট ও সার্ভিস ওয়ার্কার ফাইল।
- `android/` — সম্পূর্ণ প্রস্তুতকৃত নেটিভ অ্যান্ড্রয়েড সোর্স কোড (Capacitor/Gradle)।
- `.github/workflows/build-apk.yml` — গিটহাব অ্যাকশনস স্বয়ংক্রিয় APK তৈরির স্ক্রিপ্ট।
- `capacitor.config.json` — অ্যান্ড্রয়েড মোবাইল অ্যাপের কনফিগারেশন।
